# Fraternity Portal — Starter Application

Working UI prototype with public landing page, invitation-only membership policy, login screen, and responsive member dashboard.

## Run locally
1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

The login is currently a UI prototype. Real authentication, PostgreSQL, roles, permissions, and member data must be connected before production use.
